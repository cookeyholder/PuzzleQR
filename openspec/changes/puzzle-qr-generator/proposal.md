## Why

傳統的 QR Code 純粹是功能導向的黑白方格網格，缺乏互動樂趣與視覺美感。透過將相鄰的 QR 模組融合為長短不一的牆體，並在 Reed-Solomon 容錯率允許的預算內打通一條可通行的路徑，我們能將標準 QR Code 轉化為兼具可玩性、高質感且手機鏡頭能 100% 穩定秒掃的互動迷宮。

## What Changes

打造純前端（Vanilla JS + Canvas/SVG）的「迷宮 QR Code 產生器」網頁應用程式：
- **核心迷宮 QR 生成**：強制生成 Version 4+（33x33 以上）並使用 Level H（30% 容錯率）的 QR Code；相鄰黑格自動融合為長短牆壁；外圍留白區設置護城河出入口；內建即時解碼自檢指示儀。
- **互動玩法機制**：支援滑鼠與手機觸控按住拖曳畫線（Drag-to-Draw）；走道中心磁吸軌道避免手抖碰壁；走進死巷倒退時自動縮回擦除軌跡；提供「💡 求助提示」微光指引；終點觸發通關預覽卡片（支援目標網址跳轉與秘密純文字揭曉）。
- **多主題與雙模式匯出**：提供 4 種視覺風格選項（Cyber 賽博、Dungeon 地牢、Modern 極簡、Hedge 樹籬）；支援自訂下載檔名，並可匯出為高畫質 PNG 與純向量 SVG 格式；具備「未解題版（適合列印挑戰）」與「破關紀念版（保留通關軌跡）」雙下載模式。

## Capabilities

### New Capabilities
- `maze-qr-generator`: 核心 QR Code 矩陣生成（強制 Level H 與 Version 4+）、相鄰模組長短牆體融合、外緣護城河出入口與 A* 加權打通演算法、記憶體即時相機解碼檢測。
- `maze-gameplay`: 指針拖曳畫線互動、走道中心磁吸軌道與撞牆阻擋、倒退自動擦除機制、破關路線微光提示、通關預覽卡片與網址/純文字雙模式處理。
- `theme-and-export`: 多主題視覺樣式引擎（賽博、地牢、極簡、樹籬）、自訂下載檔名字串、雙模式（未解/已解）PNG 與原生向量 SVG 檔案匯出。

## Impact

- 全新獨立前端應用程式，無需任何後端 API、資料庫或 Node.js 打包建置工具。
- 採用輕量純 JavaScript QR 編碼與解碼模組，可直接靜態部署於 GitHub Pages 或任何網頁伺服器。
